# 사용자 제공 성공 사례의 기준

아래는 사용자가 원하는 움직임을 얻었다고 보고한 세 원문의 발췌와 요약이다. 실제 결과 영상이나 이미지 검증 기록은 아니다. 개별 문장의 효과는 분리 검증되지 않았다.

## 공통 근거

- “Google Earth navigation jump style — discrete position jumps with hard stops”
- “Everything is a frozen photograph.” / “No object moves.” / “Only camera jumps.”
- “Hard freeze 0.3s → motion blur snap forward … → hard stop.” / “Hold 0.3s.”
- “Complete dead stop.”
- “NO smooth gliding. NO moving objects. NO UI. NO arrows. NO overlays.”

재사용할 코어는 정지된 장면 속 카메라 이동, 불연속 스냅, 이동 직후 완전 정지, 명시적 횟수·순서, 시각적으로 설명된 도착 상태와 마지막 유지이다. 반복 문구와 도착 설명이 성공에 기여했을 가능성은 있지만 인과관계는 추정이다.

## 세 변형

### 5초: 전진, 관찰, 좌회전, 추가 전진

메인 도로 → 전진 20m → 사슴 관찰 → 왼쪽 90° 스냅 회전 → 골목 전진 15m → 추가 전진 15m → 최종 유지.

- 관찰 구절: “smooth slow zoom-in punch toward the frozen deer — altitude drops 25m → 10m, deer fills 60% of frame.”
- 예외 제한: “Zoom on deer is the ONLY non-jump camera move.”
- 종점: “Final hard snap forward 15m into Image 3 view”. 이 원문의 Image 3 명칭을 새 작업의 이미지 매핑에 복사하지 않는다.
- 모호함: 1.2초 관찰 구간에 줌 왕복 1.2초와 별도 0.5초 hold가 겹친다. 최종 1.2초 구간도 스냅과 1.2초 hold를 함께 지정한다. 고도 하강은 순수 줌이 아니며 “back to street level”은 복귀 고도가 명확하지 않다. 새 작업에서는 의도를 확인하고 일관되게 배분한다.

### 3초: 전진 세 번

0.00–0.80s / 0.80–1.60s / 1.60–2.40s의 각 구간에 전진 15m. 각 0.8초 구간은 0.3초 정지 + 나머지 0.2초 스냅 + 0.3초 유지로 해석 가능하다. 2.40–3.00s 최종 유지 0.6초. 원문은 스냅 자체의 0.2초를 직접 기재하지 않았으므로 이는 산술적 해석이다.

진행 구도: “Buildings closer on both sides” → “Brick facades fill both sides of frame” → “Deep inside street canyon.”

### 3초: 한 번의 큰 전진

0.00–1.00s 시작 유지. 1.00–1.50s에 “Hard freeze 0.2s → single motion blur snap forward 300m → hard stop.” 1.50–3.00s 도착 유지 1.5초.

“ONE single jump only.” / “ONE JUMP ONLY.” 횟수 제한의 재사용 예이며 300m 자체는 일반 원칙이 아니다. 이미지로 거리 구현을 검증한 사례가 아니다.

## 그대로 복제하지 않을 항목

사슴, 차량, 벽돌/베이지색 건물, 벤치, 차선, 날씨, 좌회전, 거리, 줌 대상·점유율·고도·영상 길이는 장면별 값이다. “does not move one pixel”은 피사체 자체 정지 의도로 읽히지만 카메라 이동과 화면 좌표 고정이 충돌할 수 있어 새 문장에는 자세와 세계 내 위치 보존으로 표현한다.
